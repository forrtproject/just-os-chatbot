About JUST-OS

Despite (or due to) the overwhelming amount of information on Open Science, it is practised way less than it is preached. JUST-OS is a chatbot that helps researchers and other stakeholders navigate Open Science initiatives, knowledge and resources, so that it becomes easier to put Open Science into practice.

JUST-OS uses retrieval-augmented generation. For each question it searches a library of open science literature and guides curated by FORRT (full texts where available, otherwise abstract cards) and, for questions about FORRT itself, pages on forrt.org. A large language model then writes an answer from the passages it found and cites them with numbered references: click a number to see the source behind a claim. The passage itself is shown only where the source's licence permits. Answers can still be wrong or incomplete, so check the cited sources.

The code is open source on GitHub. If you are an author or rights holder of one of the resources and don't want your work to be used by the bot, please open an issue there and we will remove it as soon as possible.
